# نصب یونی‌فایننس روی سرور شما

این بسته همه چیز لازم برای اجرای نرم‌افزار روی سرور خودتان را دارد: برنامه، پایگاه داده و گواهی HTTPS خودکار.

## پیش‌نیاز

- یک سرور لینوکس (Ubuntu 22.04 یا جدیدتر) با حداقل ۲ گیگ رم و ۲۰ گیگ دیسک
- Docker و افزونه compose: <https://docs.docker.com/engine/install/ubuntu/>
- برای دسترسی از اینترنت: یک دامنه یا زیردامنه (مثلاً `panel.example.ir`) که رکورد A آن به IP سرور اشاره کند و پورت‌های ۸۰ و ۴۴۳ باز باشند.

## نصب

فایل بسته را روی سرور باز کنید و در همان پوشه اجرا کنید:

```bash
tar xzf onprem-<name>.tar.gz && cd onprem-<name>
sudo ./install.sh --domain panel.example.ir --org "نام مجموعه" --admin-email admin@example.ir
```

در پایان، آدرس پنل، ایمیل ورود و رمز اولیه نمایش داده می‌شود. پس از اولین ورود رمز را از بخش پروفایل تغییر دهید.

- بدون دامنه (فقط شبکه داخلی): گزینه `--domain` را ندهید؛ پنل روی `http://IP-سرور` در دسترس است.
- اگر سرور به Docker Hub دسترسی ندارد، در `/etc/docker/daemon.json` یک registry mirror تنظیم کنید (مثلاً `{"registry-mirrors": ["https://docker.arvancloud.ir"]}`) یا در `.env` نام تصاویر `MARIADB_IMAGE` و `CADDY_IMAGE` را به یک mirror تغییر دهید و `docker compose up -d` را اجرا کنید.

## پیامک و درگاه پرداخت

در فایل `.env` اطلاعات پنل ملی‌پیامک (`MELIPAYAMAK_*`) و کد درگاه زرین‌پال (`ZARINPAL_MERCHANT_ID`) مجموعه خودتان را وارد کنید و سپس:

```bash
docker compose up -d
```

## پشتیبان‌گیری

```bash
./backup.sh                  # همین حالا
./backup.sh --install-cron   # هر شب ساعت ۳:۳۰
```

نسخه‌ها در پوشه `backups/` نگهداری می‌شوند (۱۴ روز). یک نسخه را هم خارج از سرور نگه دارید.

## به‌روزرسانی

فایل جدید `unifinance-image.tar.gz` را که دریافت می‌کنید کنار اسکریپت‌ها بگذارید و اجرا کنید:

```bash
./update.sh
```

قبل از به‌روزرسانی خودکار پشتیبان گرفته می‌شود و تغییرات پایگاه داده هنگام اجرا اعمال می‌شود.

## تمدید اشتراک

کلید تمدید را در پنل، صفحه «مدیریت سال مالی» ← «اشتراک نرم‌افزار» وارد کنید. نیازی به راه‌اندازی مجدد نیست.
