# راهنمای قدم‌به‌قدم: به‌روزرسانی دسکتاپ و سرور ممتاز

همه تغییرات روی شاخه `main` در GitHub قرار گرفته است. کارهای شما:

1. به‌روز کردن نسخه روی دسکتاپ مک (اختیاری، فقط برای اینکه نسخه‌تان یکی باشد)
2. نگهداری امن کلید لایسنس
3. به‌روزرسانی سرور ممتاز

---

## ۱) به‌روز کردن پروژه روی دسکتاپ (مک)

1. برنامه **Terminal** را باز کنید (Cmd + Space، بنویسید Terminal، Enter).
2. بنویسید `cd` و یک فاصله بزنید (Enter نزنید). حالا **پوشه پروژه را از دسکتاپ با موس داخل پنجره Terminal بکشید و رها کنید**؛ مسیر خودش نوشته می‌شود. بعد Enter بزنید.
3. این دو دستور را یکی‌یکی بزنید:

   ```bash
   git checkout main
   git pull
   ```

   اگر پیام «Already up to date» یا فهرستی از فایل‌ها دیدید، تمام است.

**اگر خطا دیدید:**
- `Your local changes would be overwritten`: روی دسکتاپ فایلی را تغییر داده‌اید. اگر آن تغییرات مهم نیست: `git stash` و دوباره `git pull`.
- `not a git repository`: پوشه روی دسکتاپ از GitHub clone نشده است. یک نسخه تازه بگیرید:
  ```bash
  cd ~/Desktop
  git clone https://github.com/rapexa/unifinance-momtaz.git unifinance-momtaz-new
  ```

(اگر GitHub Desktop دارید: Fetch origin ← Pull origin هم همین کار را می‌کند.)

---

## ۲) کلید لایسنس (خیلی مهم)

فایل `license-private.key` را که جداگانه گرفته‌اید:
- **داخل پوشه پروژه نگذارید و هرگز به GitHub نفرستید.**
- دو نسخه پشتیبان جای امن نگه دارید (مثلاً فلش و یک مدیر رمز عبور).
- فقط وقتی لازم است که بخواهید برای مشتری‌های دیگر پلن صادر کنید (راهنمای `deploy/README.md`). برای ممتاز لازم نیست؛ ممتاز خودکار رایگان و نامحدود است.

## ۳) به‌روزرسانی سرور ممتاز

به سرور دسترسی ندارم. این کار را خودتان انجام می‌دهید؛ حدود ۱۰ دقیقه طول می‌کشد. قبل از هر تغییری، پشتیبان پایگاه داده و برنامه فعلی گرفته می‌شود و اگر برنامه جدید بالا نیاید، نسخه قبلی خودکار برمی‌گردد.

### قدم ۱: وصل شدن به سرور
در Terminal مک بزنید (اگر نام کاربری سرور `root` نیست، آن را عوض کنید):

```bash
ssh root@130.185.75.183
```

رمز سرور را بزنید (موقع تایپ چیزی نمایش داده نمی‌شود؛ طبیعی است). اگر بار اول پرسید `Are you sure you want to continue connecting` بنویسید `yes`.

### قدم ۲: پیدا کردن پوشه پروژه روی سرور

```bash
find / -name go.mod -path "*backend*" -not -path "*/pkg/mod/*" 2>/dev/null
```

یک خط مثل `/root/unifinance-momtaz/backend/go.mod` نشان می‌دهد. پوشه پروژه همان مسیر **بدون** `/backend/go.mod` است. به آن بروید (مسیر خودتان را بگذارید):

```bash
cd /root/unifinance-momtaz
```

### قدم ۳: گرفتن نسخه جدید

```bash
git pull origin main
```

- اگر نام کاربری و رمز GitHub خواست: به‌جای رمز باید یک **توکن** بدهید (GitHub ← Settings ← Developer settings ← Personal access tokens ← Generate، دسترسی `repo`).
- اگر `not a git repository` دید: یعنی روی سرور با git نصب نشده. همین‌جا متوقف شوید و خروجی را برای پشتیبانی (یا Claude) بفرستید.

### قدم ۴: بررسی (هیچ تغییری نمی‌دهد)

```bash
./deploy/momtaz/update.sh --check
```

فهرستی با ✓ (سبز) و ! (زرد) نشان می‌دهد:
- باید «API در حال اجرا» و «فرانت از این پوشه سرو می‌شود» را ببینید.
- اگر «Node/npm نصب نیست» دید، Node را نصب کنید:
  ```bash
  curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs
  ```
- اگر «پوشه فرانت پیدا نشد» یا «فایل‌های تغییرکرده روی سرور هست» دید، خروجی کامل را کپی کنید و بفرستید؛ قدم بعد را نزنید.

### قدم ۵: به‌روزرسانی

```bash
./deploy/momtaz/update.sh
```

چند دقیقه صبر کنید. در پایان باید «**به‌روزرسانی با موفقیت انجام شد**» را ببینید. سپس با `exit` از سرور خارج شوید.

### قدم ۶: بررسی سایت
1. سایت را باز کنید و وارد شوید (اگر صفحه قدیمی دیدید، Cmd + Shift + R).
2. داشبورد باید طرح جدید را داشته باشد.
3. منوی «مدیریت سال مالی»: بالای صفحه باید **«اشتراک ویژه مالک — رایگان · نامحدود»** باشد.
4. در همان صفحه، بخش «مشخصات مجموعه»: نام را «گروه مشاوره ممتاز» بگذارید و ذخیره کنید. این نام در صفحه پرداخت دانش‌آموزان و پیامک‌ها نمایش داده می‌شود.

### اگر مشکلی پیش آمد
- اسکریپت در صورت خطا نسخه قبلی API را برمی‌گرداند. پشتیبان‌ها در پوشه `backups/` پروژه روی سرور هستند.
- اگر روی سایت بنر «لایسنس ثبت نشده» دیدید (نباید ببینید): در `backend/config.yaml` این دو خط را به انتهای فایل اضافه کنید و دوباره قدم ۵ را بزنید:
  ```yaml
  license:
    owner: true
  ```
- هر خطایی دیدید، کل متن Terminal را کپی کنید و بفرستید.
